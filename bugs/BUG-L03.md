# BUG-L03 — led rgb змінює колір активної лампи

**Версії:** 1.3 / 1.4 / 1.5.  
**Severity / Priority:** Minor / Medium.  
**PRD:** [PRD, розділ 4; FR-L8](../reference/PRD.md#4-smart-lamp).

**Передумови:** Лампа on/blue/blink/timer 0; brightness 37 на 1.3/1.4, 50 на 1.5.

**Кроки:**

1. Ввести `led rgb` і спостерігати цикл.
2. Ввести `lamp status`.

**Очікувано:** Лампа продовжує блимати синім; led-команди не впливають на неї.

**Фактично:**

Під час циклу з’являються інші фізичні кольори, JSON залишається blue/blink. На 1.5 led on/off/auto окремо не змінили лампу. Супровідні RMT-помилки є в логу; причинний зв’язок не встановлено.

```text
{"lamp":"on","color":[0,0,255],"brightness":50,"mode":"blink","timer_s":0}
```

**Відтворюваність:** Фізично підтверджено на всіх трьох версіях; результат кожного виклику окремо не рахували.
