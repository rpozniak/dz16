# BUG-L04 — Blink ігнорує яскравість, включно з 0%

**Версії:** 1.5; на 1.3/1.4 blink 10/100 працював.  
**Severity / Priority:** Minor / Medium.  
**PRD:** [FR-L5](../reference/PRD.md#fr-l5), [FR-L8](../reference/PRD.md#fr-l8).

**Передумови:** 1.5, lamp on, RGB [255,0,128], blink, timer 0.

**Кроки:**

1. Послідовно виконати `lamp brightness <N>` для N=0, 1, 50, 100.
2. Після кожної — `lamp status` та візуальне порівняння спалахів.

**Очікувано:** Яскравість спалахів змінюється; при 0% світіння немає.

**Фактично:**

JSON приймає всі значення, фізична яскравість не змінюється; при 0% спалахи залишаються. Solid/rainbow регулюються, breathe при 5% видимий.

```text
{"lamp":"on","color":[255,0,128],"brightness":0,"mode":"blink","timer_s":0}
```

**Відтворюваність:** Один прогін 0/1/50/100. Регресія регулювання щодо 1.4; 0% у старих версіях не перевіряли.

**Докази:** [UART і фізичне підтвердження](../logs/v1.5.0_blink_brightness_ignored.log), [контроль 1.4](../logs/20_v1.4.0_blink_breathe_brightness.log). Фото/відео немає; фізичний результат прямо підтверджений користувачем.
