# Фізичні результати

Джерело — відповіді користувача під час ручного виконання. UART засвідчує команди/JSON, а не фізичне світіння.

| Перевірка | 1.3 | 1.4 | 1.5 |
|---|---|---|---|
| on/off | Працює | Працює; off/connected — тьмяний зелений | Працює; off/disconnected — тьмяний червоний |
| Кольори | Red/green і purple/cyan переплутані; blue/white/yellow правильні | 7 названих та числовий набір правильні | 7 названих; RGB 255/0/128, red/green/black правильні |
| Яскравість | Solid 0/10/100, blink/breathe 10/100 змінюються | Те саме | Solid/rainbow змінюються; breathe при 5% видимий, 1% не оцінений; blink 0/1/50/100 незмінний, при 0% спалахи є |
| Режими | Solid/blink/breathe відповідають | Відповідають | Solid/blink/breathe/rainbow відповідають; дефект яскравості blink окремо |
| Timer 5 | Біле згасло, червоний індикатор | Біле згасло, тьмяний червоний | Біле залишилось як до expiry; timer 1 — те саме; ручне off прибирає біле |
| led rgb при lamp on/blue/blink | З’являються інші кольори | Те саме | Те саме; led on/off/auto окремо не змінюють лампу |
| Сцени | Не реалізовано | Не реалізовано | Load 1/2/3 фізично відновлює параметри; після reboot/USB повторний load при on працює |

Фотографій/відео для всіх сценаріїв немає. Світловий потік і періоди приладом не вимірювалися. Точний фізичний результат кожного повтору led rgb окремо не рахували.
