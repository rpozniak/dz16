# HW-16 — Тестування Smart Lamp та OTA

**Виконав: Pozniak.**

Ручне тестування прошивок **1.3.0, 1.4.0 та 1.5.0** на ESP32-S3 DevKit: керування лампою, OTA-оновлення, збереження налаштувань, обрив Wi-Fi, захист від даунгрейду та автоматичний rollback.

Почати перевірку роботи зі **[звіту REPORT.md](REPORT.md)**: у ньому чекліст за версіями, матриця багів, результати OTA-переходів і висновок щодо готовності 1.5.0 до stable.

Докази та вимоги:

- [bugs/](bugs/) — баг-репорти з кроками відтворення й посиланнями на докази.
- [logs/](logs/) — UART-логи, фото та скриншоти.
- [PRD.md](reference/PRD.md) — вимоги до прошивки.

[requirements.txt](requirements.txt) — інструменти для стартового прошивання (`esptool`) та UART (`pyserial`); допоміжні залежності встановлюються автоматично.
